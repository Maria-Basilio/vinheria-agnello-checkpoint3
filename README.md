
# Vinheria Agnello - Checkpoint 03

Vinheria Agnello - Sistema de Controle de Estoque

## Descrição do projeto

Este projeto foi desenvolvido para o Checkpoint 03 da disciplina de Web Development, onde o sistema simula o controle de estoque de uma vinícola, utilizando objetos, arrays, funções reutilizáveis e métodos de array para organizar as informações dos vinhos.

### Funcionalidades implementadas

- Cadastro de novos vinhos por meio da função `adicionarVinho()`.
- Listagem de todos os vinhos com `forEach()`.
- Identificação dos vinhos com estoque abaixo de 5 unidades utilizando `filter()`.
- Cálculo do estoque total utilizando `reduce()`.
- Exibição dos nomes dos vinhos em letras maiúsculas utilizando `map()`.

Os resultados são exibidos no console do navegador por meio de `console.log()`, não usando formulários, `prompt()` ou manipulação do DOM para as interações.
