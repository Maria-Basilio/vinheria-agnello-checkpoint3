Sistema de Controle de Estoque

O vinho é muito mais do que uma simples bebida: ele representa história, cultura e tradição. Na Vinheria Agnello, cada garrafa possui sua própria identidade.

Este projeto utiliza JavaScript para simular o controle de estoque de uma vinícola. O sistema permite cadastrar vinhos e gerar relatórios para acompanhar os produtos.

Relatórios do estoque

O JavaScript gera relatórios com a lista de vinhos, os produtos com estoque baixo, a quantidade total de garrafas e os nomes dos vinhos em letras maiúsculas.

Para visualizar os resultados, abra as ferramentas do desenvolvedor do navegador e acesse a aba Console.
